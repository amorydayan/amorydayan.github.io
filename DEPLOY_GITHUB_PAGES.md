# Déploiement sur GitHub Pages

Ce document explique comment préparer le portfolio pour un déploiement futur sur GitHub Pages.

## 1. Créer un dépôt GitHub

Créer un dépôt public nommé :

- omar-dayan-portfolio

## 2. Publier uniquement le contenu du site

Publier uniquement le dossier suivant :

- website/

Ne pas publier le dossier complet D:\Téléchargement google\Portfolio, car il contient des rapports, des archives sources et d’autres fichiers non destinés à la publication publique.

## 3. Activer GitHub Pages

Dans le dépôt GitHub :

1. Ouvrir les paramètres du dépôt
2. Aller dans Pages
3. Choisir le mode Deploy from a branch
4. Sélectionner la branche principale
5. Choisir le dossier racine ou le dossier site si le dépôt contient uniquement le site web
6. Enregistrer

## 4. URL approximative

Une URL typique sera de la forme :

- https://USERNAME.github.io/omar-dayan-portfolio/

## 5. Mettre à jour le site plus tard

Avec VS Code :

1. Ouvrir le dépôt local
2. Modifier les fichiers HTML, CSS, JS ou assets
3. Utiliser Git pour valider les changements
4. Pousser vers GitHub
5. Vérifier la page sur l’URL GitHub Pages

## Bonnes pratiques

- Ne pas publier les originaux de rapports ou archives ZIP
- Vérifier les images qui peuvent contenir des informations internes
- Valider le CV avant publication publique
- Répéter la vérification des liens externes lors d’une mise à jour
